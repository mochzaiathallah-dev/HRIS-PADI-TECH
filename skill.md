# AI Skill Capabilities

- **Client-Side Image Processing:** Mampu memberikan skrip untuk memotong (*crop*) dan mengompresi gambar (bukti *screenshot* GMV TikTok) langsung di dalam *browser* pengguna (*client-side*) menggunakan Canvas API atau *library* kompresi web sebelum dikirim ke Supabase. Ini menghemat *bandwidth* klien dan *storage* Supabase.
- **Client-Side Document Parsing:** Mampu mem- *parsing* CSV atau laporan tabular langsung di *browser* (*Papaparse*) untuk fitur unggah data massal ke *database* tanpa memerlukan pemrosesan di *server* Vercel.
- **Realtime Listener Debugger:** Memiliki kemampuan menganalisis kode *channel* WebSocket Supabase untuk mencegah *memory leaks* di aplikasi React akibat *listener* yang tidak dibersihkan (*unmounted*) dengan benar.
